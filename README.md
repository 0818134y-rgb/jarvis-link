# JARVIS Link — PC と Android で動く音声AIアシスタント

「ジャーヴィス、スマホのライトをつけて」「パソコンでメモ帳を開いて」のように、
**PC(Windows)とAndroidがそれぞれ単独で動き、必要な時だけお互いに指示を送り合う** 音声アシスタントです。
どちらも完全ローカル(クラウドAPI不要・無料)で動きます。

```
 ┌──────────── PC (Windows) ────────────┐        ┌────────── Android ──────────┐
 │ faster-whisper → 自作AIエンジン →    │        │ 端末内音声認識 → 自作AIエンジン │
 │ ツール実行 → VOICEVOX                │        │ → ツール実行 → 端末TTS        │
 │  ├ アプリ/ウィンドウ/メディア         │        │  ├ アプリ/ライト/音量/タイマー │
 │  ├ ファイル/ブラウザ                  │        │  ├ 電話/SMS下書き/ナビ        │
 │  ├ 画面の項目を番号で操作(UIA)       │        │  └ 画面操作(ユーザー補助)     │
 │  └ PowerShell(確認付き)              │        │                             │
 │        WebSocket サーバー :8765  ◀────┼─ HMAC相互認証 ─┼──▶ WebSocket サーバー :8765 │
 └──────────────────────────────────────┘  同一Wi-Fi: mDNSで自動発見 └─────────────────────────────┘
                                            外出先: Tailscale のIPを手動登録
```

## フォルダ構成

| パス | 内容 |
|---|---|
| `pc/` | PC版 (Python)。`jarvis/tools/` に操作ツール、`jarvis/link.py` が連携 |
| `android/` | Android版 (Kotlin / Jetpack Compose)。Android Studio で開く |
| `protocol/PROTOCOL.md` | 端末間通信の仕様 (他の端末を追加したい時に) |

---

## 1. PC版のセットアップ (Windows 11)

1. `pc\JARVIS.bat` をダブルクリック
   (Python 3.12 が無ければ自動で用意します。3.13より新しいPythonしか無い場合も、3.12を追加して使います)

これだけです。初回は Python 環境の作成とパッケージのインストールを自動で行います(数分)。
VOICEVOX がインストールされていれば自動で起動し、無ければWindows標準の声で話します。
PC版の頭脳もAndroidと同じ**自作AIエンジン**(同じ学習済みモデル)で、OllamaなどのAIは不要です。
音声の聞き取りだけは Whisper(faster-whisper)を使い、初回起動時に約500MBのデータを自動で取得します。

初回起動時に表示される **連携トークン** をスマホに入力します(`pc\.jarvis_token` にも保存されます)。
マイクなしで試すなら `JARVIS.bat --text`。

### PCでできること(例)

| 分野 | 言い方の例 |
|---|---|
| アプリ・ウィンドウ | 「メモ帳を開いて」「Chromeを閉じて」「ウィンドウを最大化して」「デスクトップを表示して」 |
| ブラウザ | 「新しいタブを開いて」「タブを閉じて」「次のタブ」「戻って」「更新して」「ページ内でログインを探して」「拡大して」 |
| サイト内検索 | 「Amazonでイヤホンを探して」「YouTubeで猫動画を再生して」「食べログで新宿のラーメン」 |
| 画面の操作 | 「画面の項目を教えて」→「3番をクリック」/「保存ボタンを押して」「〇〇と入力して」「保存して」「コピーして」 |
| ファイル | 「見積書というファイルを探して」→「1番を開いて」/「ダウンロードフォルダを開いて」 |
| タイマー等 | 「5分のタイマー」「7時半にアラーム」「スクショ撮って」「画面をロックして」 |
| 連続指示 | 「YouTubeを開いて、猫動画を検索して」 |
| スマホへ | 「スマホのライトをつけて」「スマホを探して」「このページをスマホで開いて」「スマホの通知を読んで」 |

ライト・電話・SMS・写真・カレンダーなどスマホにしかできないことは、PCに言っても自動でスマホに頼みます。

**話しかけ方**: 「ジャーヴィス、〇〇して」/ `Ctrl+Alt+J` を押してから話す / 返答後6秒以内ならそのまま続けて話せる

## 2. Android版のセットアップ

1. Android Studio(Ladybug 以降)で `android/` フォルダを開く → Gradle 同期 → 実機で ▶ 実行(Android 8.0以上)
   *コマンドラインでビルドする場合は先に `gradle wrapper` を一度実行して gradlew を生成してください。*
2. 起動時に マイク・通知・連絡先・電話 の権限を許可
3. 右上の ⚙ → **連携トークン** にPCで表示された値を入力 → 「保存して再接続」
4. ⚙ → 「ユーザー補助を開いて…」→ **JARVIS 端末操作** をオン(画面操作・裏からのアプリ起動に必要)
5. ⚙ → 「電池の最適化を解除」(画面オフでもPCからの指示を受けるため)
6. 天気で現在地を使うため、位置情報の権限も許可してください(許可しない場合は「大阪の天気」のように地名で聞けます)

### Android版の頭脳: 自作AIエンジン

外部のAI(ChatGPTやClaude、Gemmaなど)は使わず、ゼロから作ったエンジンで動きます。APIキー不要・無料です。

| 段階 | 中身 | ファイル |
|---|---|---|
| 意図理解 | 約60種類の意図(ライト、天気、雑談…)を見分けるモデルを**自前で学習**。文字n-gram+ソフトマックス回帰をnumpyで一から実装 | `brain/dataset.py` `brain/train.py` → `assets/brain/` |
| 情報の取り出し | 「何分」「どのアプリ」「どこの天気」「何を計算」などを抽出 | `brain/Brain.kt` `agent/Rules.kt` |
| 対話管理 | 足りない情報は聞き返す(「タイマーかけて」→「何分にしますか？」)、削除などは「はい/いいえ」で確認、直前の話題を覚える(「明日は？」「続き」) | `brain/Brain.kt` |
| 知識・スキル | 天気(Open-Meteo)、Wikipedia、ニュース(Google ニュース RSS)、為替、日本語の計算、記念日までの日数、名前やメモの記憶、雑談 | `brain/*.kt` |

**話しかけ例**: 「明日の大阪の天気は？」→「週末は？」/「富士山って何？」→「もっと詳しく」/「12かける8は？」/
「1ドルは何円？」/「ニュースを教えて」→「続き」/「クリスマスまであと何日？」/「私の名前はゼンです」/
「牛乳を買うって覚えておいて」→「メモを読んで」/「晩ご飯何にしよう」/「サイコロ振って」/「何ができる？」

**言い方を増やす・意図を追加する**: `brain/dataset.py` に例文を足して `python brain/train.py`(要 numpy)で再学習し、
意図を増やした場合は `Brain.kt` の `dispatch` に応答を書きます。学習時にKotlin側と推論結果が一致するかのテスト用データも出力され、
GitHubでのビルド時に自動で確認されます。

**話しかけ方**: 「ジャーヴィス、〇〇して」と呼ぶだけ(ボタン不要・ビープ音なし)。返事の後7秒間は呼びかけなしで続けて話せます。
反応しにくい時は ⚙ →「音声」の「最後に聞こえた言葉」を見て、「今の言葉を呼びかけとして登録」を押してください。
声は男性の声を自動で選びます(⚙ →「声」で変更・試聴可)。

## 3. 連携のしかた

* **同じWi-Fi**: 両方起動すれば数秒で自動的に見つかります(画面の「連携 1台」)
* **外出先**: 両方に [Tailscale](https://tailscale.com/) を入れて同じアカウントでログイン →
  * スマホの ⚙「手動ピア」に PC の Tailscale IP を `100.x.y.z:8765` 形式で入力
  * PC の `config.yaml` の `link.peers` にスマホの Tailscale IP を入力
* 名前は「pc」「phone」が既定。「パソコン」「スマホ」「携帯」などの言い方でも通じます

### 話しかけ例

| どこで | 言うこと | 起きること |
|---|---|---|
| PC | ジャーヴィス、スマホのライトをつけて | スマホのライト点灯 |
| PC | ジャーヴィス、スマホで10分のタイマー | スマホでタイマー開始 |
| PC | ジャーヴィス、クリップボードをスマホに送って | PCのコピー内容がスマホへ |
| PC | ジャーヴィス、画面の項目を教えて → 3番をクリック | 押せる項目を番号で読み上げてクリック |
| PC | ジャーヴィス、ダウンロードの見積書を探して → 1番目を開いて | ファイル検索→開く |
| スマホ | パソコンで音楽を止めて | PCの再生を一時停止 |
| スマホ | パソコンのクリップボードを取り込んで | PCのコピー内容がスマホへ |
| スマホ | パソコンに「ご飯できたよ」と読み上げて | PCがVOICEVOXで読み上げ |
| スマホ | このページをパソコンで開いて | スマホで見ているページをPCのブラウザで開く |
| PC | このページをスマホで開いて | PCで見ているページをスマホで開く |
| PC | スマホを探して | スマホが最大音量で15秒鳴る |
| スマホ→PC | (設定で通知転送をオン) | スマホに届いた通知がPCに表示される。「スマホの通知を読んで」で読み上げ |
| スマホ | パソコンでYouTubeを開いて、猫動画を検索して | PCで連続操作 |

## 4. 安全設計

* トークンは通信路に流さず、HMAC-SHA256 の **相互認証**(偽の端末に指示を送らない・受けない)
* 他端末からの依頼では **画面操作・画面読み取り・シェル・削除・発信は既定で拒否**
  (PCは `allow_remote_dangerous`、スマホは⚙のスイッチで許可可能。Tailscale等の閉じた網でのみ推奨)
* ローカルでも **PowerShell実行・ファイル移動/削除・強制終了・スリープ・発信** は音声で「はい」と答えるまで実行しない
* 削除はごみ箱へ移動のみ。SMSは下書きを開くだけで送信ボタンは本人が押す
* 同一Wi-Fi内の通信は暗号化されていません(認証のみ)。外出先は Tailscale(WireGuard暗号化)経由にしてください

## 5. 既知の制約

* Android はOSの制限で、裏で動いている時は **クリップボードを読めません**(書き込みは可)。
  スマホ→PCへの送信はJARVISの画面を開いた状態で行ってください
* Android 14+ ではマイクを使う常駐はアプリが前面にある時しか開始できないため、
  端末再起動後は一度JARVISを開いてください
* 常時待ち受けは端末の音声認識を繰り返し起動する方式です。機種によっては開始音が鳴り、電池消費も増えます
* 画面を見てクリックする機能(ビジョンモデル)はメインモニターのみ対象で、精度は画面次第です。
  先にUI Automation で名前一致を探すので、ボタン名を言うのが確実です
* 自作AIは決められた範囲(約60種類の意図)の会話に強い一方、自由な長文の会話はできません。わからない質問はWikipediaで調べ、それでもだめならブラウザ検索を提案します

## 6. 機能を足す

* **PCにツール追加**: `pc/jarvis/tools/` に関数を書いて `@registry.add(...)` を付けるだけ(LLMに自動で渡る)
* **Androidにツール追加**: `tools/*.kt` で `add("name", "説明", Param(...)) { args -> ... }`
* **言い方・意図の追加**: `brain/dataset.py` に例文を足して `python brain/train.py`
* **別の端末を追加**(ラズパイ、Mac等): `protocol/PROTOCOL.md` に従ってサーバーを実装すれば、名前で指示できます
